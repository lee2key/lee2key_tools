# lee2key_tools для Houdini

Инструменты доступны в верхнем меню **lee2key_tools**, перед **Help**.

## Установка и обновление

1. Скопируйте папку `packages` из репозитория в папку настроек Houdini
   (`Documents/houdiniXX.X`), сохранив файл `packages/lee2key_tools.json`.
2. При обновлении с версии с полкой удалите старый файл
   `packages/lee2key_tools/toolbar/lee2key_tools.shelf` из установленной копии.
3. Перезапустите Houdini. Меню появится автоматически; добавлять полку не нужно.
   Если старая полка осталась в сохранённом Layout, закройте её вкладку
   и сохраните Layout заново.

## Команды меню

- **Last Project** — открыть последний проект из истории Houdini.
- **Import-Export** — без выделения импортировать геометрию; с одним выделенным
  узлом экспортировать её через общий временный файл для Blender и Cinema 4D.
- **Create Null** — создать Null после выделенного узла или в текущей сети.
- **Object Merge** — создать Object Merge по пути узла из буфера обмена.
- **Redshift** — подменю с командами:
  - **Create Setup** — создать камеру, свет, материалы и рендер-сеть для Redshift.
  - **New Material** — создать материал Redshift.
  - **Preview Node** — подключить выбранный узел Redshift к выходу для просмотра.
  - **Texture Scale** — создать общий узел масштаба для выбранных текстур Redshift.
- **Information** — открыть страницу проекта в Telegram.

Команды используют текущую сеть и выделение так же, как прежние кнопки.
Инструменты Redshift требуют установленного Redshift. Цифровые ассеты HDA
по-прежнему доступны через меню Tab.
