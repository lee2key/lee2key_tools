lee2key_tools — это плагин для Houdini. В основном полезен, если вы используете Redshift.
Кроме Houdini также есть два плагина для Blender и Cinema 4D, которые позволяют быстро экспортировать файлы между тремя программами.

Установка плагина для Houdini:
Cкопируйте папку "packages" в C:\Users\USERNAME\Documents\houdiniXX.X
После запуска Houdini вам нужно добавить полку с кнопками вверху. Нажимаете на "+" и ищите lee2key_tools. Затем можно сохранить Layout.

Установка плагина для Cinema 4D:
В Cinema 4D перейдите вверху в меню Extensions — User Scrips — Script folder... Откроется папка с настройками Синемы, где надо открыть папку scripts и скопировать туда файлы lee2key_tools_CopyToC4D.py и lee2key_tools_C4DCamera.py.
Они находятся в архиве плагина в папке packages/lee2key_tools/plugins/Cinema 4D
После перезапуска Cinema 4D у вас появится эти скрипты там же в меню Extensions — User Scripts. Далее уже можно перетащить иконки в нужное месте в интерфейсе и сохранить Layout, или лучше просто назначить хоткеи на эти скрипты.

Установка плагина для Blender:
Зайдите в настройки блендера во вкладку Add-ons, нажмите на стрелочку справа вверху и выберите Install from Disk. Выберите архив из папки packages/lee2key_tools/plugins/Blender
Далее нужно установить хоткей на функцию lee2key_tools во вкладке с хоткеями. Я поставил на "4".
